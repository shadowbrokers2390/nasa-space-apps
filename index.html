About this data

    Limits: read before trusting a number

    • One direction only. The radar measures motion toward or away from itself, not the full 3D movement, which is larger. The two viewing directions give different numbers for the same motion because each sees a different slice of it.
    • Relative, not absolute. Each date pair is measured against the typical pixel in this map area.
    • Background noise. Anything inside that range should not be read as motion.
    • The amount may be underestimated. Where the ground moves a lot between neighboring pixels, the processing can lose whole steps of cm. Treat the values as "at least".
    • Totals add up errors. The chart and the total map add date pairs end to end, so each pair's noise adds in too. On the total map a cell needs data in at least 80% of the pairs, and its missing pairs count as zero.
    • Not everything colored is ground motion. Broad pale bands that follow the hills are probably weather effects in the air.
    • No cause is proven.
    • Coarse pixels. Each pixel is about m, so this shows areas, not individual houses.

    What an engineer would check on the ground

    The satellite shows where to look. Ground instruments show how deep, how fast, and in which direction.
